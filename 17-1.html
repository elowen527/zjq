JSON 数据格式

JSON（JavaScript Object Notation）是轻量的数据交换格式：键必须用双引号，值只有六种类型。本页从语法解剖、对象与字符串互转、格式化校验到用 JSON 渲染表格，把 JSON 一次讲透。

二、JSON.stringify 与 JSON.parse：对象 ⇄ 字符串

stringify 把 JS 对象序列化成 JSON 字符串（常用于传输/存储），parse 把 JSON 字符串解析回 JS 对象（常用于接收数据）。
