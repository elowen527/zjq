四、速查表：20 个方法一眼分清

            
面试和写代码时最常查的一张表。改动原数组的方法要小心，它们会悄悄改掉你原来的数据。


            

                

                    颜色说明：橙色 = 会改变原数组　青色 = 原数组保持不变
                    
                        

                            方法
                            干什么用
                            是否改变原数组
                            返回值
                        

                    
                    
                        

                            push()
                            在尾部添加一个或多个元素
                            改变
                            新的长度
                        

                        

                            pop()
                            删除最后一个元素
                            改变
                            被删掉的元素
                        

                        

                            unshift()
                            在头部添加元素，其余元素后移
                            改变
                            新的长度
                        

                        

                            shift()
                            删除第一个元素，其余元素前移
                            改变
                            被删掉的元素
                        

                        

                            splice()
                            在任意位置删除、插入、替换元素
                            改变
                            被删元素组成的新数组
                        

                        

                            slice()
                            按范围截取一段（含头不含尾）
                            不变
                            新数组
                        

                        

                            concat()
                            把另一个数组接到后面
                            不变
                            新数组
                        

                        

                            join()
                            用分隔符把元素连成一个字符串
                            不变
                            字符串
                        

                        

                            reverse()
                            原地首尾翻转
                            改变
                            翻转后的原数组
                        

                        

                            sort()
                            原地排序，数字排序必须给比较函数
                            改变
                            排序后的原数组
                        

                        

                            indexOf()
                            从前向后找某个值的位置
                            不变
                            下标，找不到返回 -1
                        

                        

                            includes()
                            判断数组里有没有这个值
                            不变
                            true / false
                        

                        

                            find()
                            找第一个满足条件的元素
                            不变
                            元素本身，找不到是 undefined
                        

                        

                            findIndex()
                            找第一个满足条件的元素的下标
                            不变
                            下标，找不到返回 -1
                        

                        

                            forEach()
                            逐个访问，纯粹执行操作
                            不变
                            undefined（没有返回值）
                        

                        

                            map()
                            逐个加工，一一对应
                            不变
                            等长的新数组
                        

                        

                            filter()
                            逐个筛选，留下条件为真的
                            不变
                            可能更短的新数组
                        

                        

                            reduce()
                            带着累积器一路归并成一个值
                            不变
                            归并出来的单个值
                        

                        

                            some()
                            只要有一个满足条件就停
                            不变
                            true / false
                        

                        

                            every()
                            必须全部满足条件
                            不变
                            true / false
