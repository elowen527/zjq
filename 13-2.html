Lucide SVG 图标

Lucide 是基于 Ionicons 开源图标库构建的 SVG 图标集。每个图标都是独立的 SVG 矢量图形，通过 lucide.js 的 createIcons() 方法将带有 data-lucide 属性的元素替换为内联 SVG。SVG 图标可通过 CSS 的 width、height、color、stroke-width 等属性灵活控制样式。

字体图标 vs SVG 图标

两种图标技术对比

Font Awesome（字体图标）

通过 @font-face 加载字体文件，使用 CSS 伪元素映射 Unicode 字符。优点：兼容性好，一次加载全部图标。缺点：无法使用多色图标，伪元素可访问性较差。

Lucide（SVG 图标）

每个图标都是独立的 SVG 矢量图形，通过 JS 动态插入内联 SVG。优点：支持多色、描边可控、CSS 样式灵活、可访问性好。缺点：需要 JS 支持，按需加载需额外配置。
