CSS 长度单位

绝对单位

绝对单位是固定的物理尺寸，不随其他因素变化。

px（像素）：width: 200px; height: 100px;
最常用的单位，1px 对应屏幕上的一个像素点。
pt（点）：width: 150pt; height: 80pt;
常用于打印，1pt = 1/72 英寸。
cm（厘米）：width: 5cm; height: 2cm;
物理厘米单位，主要用于打印样式。
mm（毫米）：width: 50mm; height: 20mm;
物理毫米单位，1cm = 10mm。
in（英寸）：width: 2in; height: 1in;
1in = 2.54cm = 96px，主要用于打印。

相对单位

相对单位基于其他元素或视口大小动态计算，更适合响应式设计。

em：相对于父元素的字体大小。
父元素 font-size: 20px → 1.5em = 30px
rem：相对于根元素（html）的字体大小。
根元素 font-size: 16px → 1.25rem = 20px
%（百分比）：相对于父元素的比例。width: 50%;
vw（视口宽度）：相对于视口宽度。width: 50vw; = 视口宽度的 50%
vh（视口高度）：相对于视口高度。height: 30vh; = 视口高度的 30%

其他单位

ch：相对于字符 "0" 的宽度。
width: 40ch; — 常用于限制文本行宽。
ex：相对于字体 x-height 的高度。
font-size: 2ex; — 较少使用。
vmin / vmax：
width: 50vmin; = 视口较小边的 50%
width: 50vmax; = 视口较大边的 50%

单位对比总结

单位 类型 说明 常见用途
px绝对屏幕像素点最常用，边框、定位等
pt绝对1/72 英寸打印样式
in绝对1in = 96px打印样式
cm / mm绝对物理长度打印样式
em相对相对于父元素 font-size字体、内边距等
rem相对相对于根元素 font-size响应式字体、间距
%相对相对于父元素宽度、高度、定位
