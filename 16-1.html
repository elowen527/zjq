JavaScript 数组方法

数组是最常用的数据结构。本页把数组方法做成可视化舞台：下面的小方块就是数组元素，点击按钮执行方法，观察数组如何实时变化；迭代方法则以「管道」的形式展示数据从进到出的全过程。

一、数组舞台：增删元素一目了然

push / pop 操作尾部，shift / unshift 操作头部，splice 可以在任意位置插入或删除。橙色高亮表示刚刚被操作的元素。

查找方法 —— indexOf 与 includes

indexOf 返回元素下标（找不到返回 -1），includes 只回答「有没有」。

  • indexOf('香蕉')返回下标或 -1
  • includes('香蕉')返回 true / false
输入元素后点击「查找」。

不改变原数组 —— slice / concat / join

这三个方法都会返回新数组或新字符串，原数组保持不变。

点击按钮查看返回值（原数组不受影响）。

二、迭代方法：数据像流水线一样加工

map、filter、reduce 是函数式编程三剑客：map 逐个加工，filter 逐个筛选，reduce 汇总成一个值。点击「运行」看每个元素如何流过管道。
