JavaScript 六种数据类型

JavaScript 的值分为六种数据类型：前五种是基本类型，变量里直接保存值；Object 是引用类型，变量里保存的是地址。点击卡片里的示例可现场运行，并查看 typeof 的检测结果。

基本类型 × 5

Number · String · Boolean · Undefined · Null

引用类型 × 1

Object —— 普通对象、数组、函数都属于它

typeof 检测器

输入任意 JavaScript 值试试，例如 123、"张钧乔"、true、null、[1, 2, 3]、({ a: 1 })。

等待输入……输入后按回车或点击「检测」，内容会被当作 JavaScript 表达式运行。

容易混淆的四个点

  • typeof null 返回 "object"：历史遗留问题，null 仍是独立的基本类型。
  • typeof [] 返回 "object"：判断数组请使用 Array.isArray()。
  • typeof function(){} 返回 "function"：但函数本质上也是对象。
  • NaN === NaN 结果为 false：判断 NaN 要用 isNaN()。
