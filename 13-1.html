Font Awesome 字体图标

Font Awesome 通过@font-face 加载图标字体文件，使用 CSS 伪元素将 Unicode 字符映射为矢量图标。只需一个 CSS 文件和字体文件，即可使用数千种图标，且可通过 CSS 的 font-size、color 等属性直接控制样式。
