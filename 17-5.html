JavaScript 两种定时器

setTimeout 是"闹钟"——到点只响一次；setInterval 是"闹钟"——每隔一段固定时间反复响。它们都返回一个编号 ID，配对的 clearTimeout / clearInterval 用这个 ID 取消定时。本页用三组可交互演示展示它们的区别。

一、setTimeout：只响一次的闹钟

延迟指定毫秒后执行一次回调。在回调执行前，可以随时用 clearTimeout 取消——下面在进度条走完前点「取消」试试。

var zjq_timerId = setTimeout(function () {
    console.log('时间到！');
}, 5000);
// clearTimeout(zjq_timerId) 可在执行前取消
点击「开始计时」启动 5 秒定时器

执行日志会显示在这里。

三、两种定时器对比

核心区别：执行次数。一个「到点只执行一次」，一个「按周期反复执行」。

方法执行方式返回值取消方法典型用途
setTimeout(fn, ms)延迟 ms 毫秒后执行 1 次定时器 ID（数字）clearTimeout(id)延迟提示、防抖、动画收尾
setInterval(fn, ms)每过 ms 毫秒执行 1 次，反复执行定时器 ID（数字）clearInterval(id)时钟、轮播、轮询刷新
两个注意点：① 回调由浏览器事件循环调度，实际延迟 ≥ 设定值（页面繁忙时更久）；② setInterval 若回调耗时超过间隔会造成堆积，可用「setTimeout 递归模拟」替代：每次回调结尾再安排下一个 setTimeout。
