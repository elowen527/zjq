# 项目规范 —— 前端练习作品集

本项目是纯静态 HTML/CSS 课程作业作品集：无构建步骤、无包管理器、无依赖、无测试，直接在浏览器打开 `index.html`。执行任何任务前必须遵守以下规范。

## 1. 命名规范（强制）

- 所有 CSS 类名、ID 名必须以 `zjq_` 开头，例如 `zjq_hero`、`zjq_work-card`
- 所有 JS 变量名必须以 `zjq_` 开头，例如 `zjq_box`
- 旧页面中已有的 `zhang_` 前缀代码在编辑时保持原样，不做批量重命名，除非用户明确要求重构

## 2. 页头注释规范（强制）

每个**新建**的 HTML 文件都必须包含页头注释，格式如下：

```html
<!-- 姓名：张钧乔，建立时间：YYYY-MM-DD HH:mm:ss，使用的大模型：模型名，功能名称：页面功能描述 -->
```

- 建立时间使用实际创建时间（精确到秒，如 `2026-10-26 13:39:29`）
- 使用的大模型填写生成该页面所用的模型名（如 `GLM-5.3`）
- 功能名称简要描述页面用途（如 `CSS3 3D动画练习`）
- 编辑已有页面时若缺少页头注释则补上；旧页面的模型字段可省略或填写最后编辑它的模型

## 3. 提示词记录流程（每次执行前）

先将用户提示词**追加**写入 `zhang_prompt.md`（不覆盖已有内容），写入内容包括：时间、使用的模型、提示词原文。格式与文件中已有条目保持一致：

```markdown
---

## 2026-10-22 15:30:00

**Model:** 模型名

**Prompt:**
提示词内容
```

## 4. 页面规范

- 仅使用原生 HTML/CSS/JS：不引入 CDN、框架、第三方库或任何外部资源
- 图标统一使用 `font/` 目录下的 iconfont 图标（阿里巴巴矢量图标库，`font/iconfont.css` + `iconfont-*.woff2`）：通过 `<link>` 引入本地样式表，用 `<span class="iconfont icon-xxx">` 显示；禁止使用 Font Awesome、Lucide 或其他图标库。旧页面中引用 `cdn/` 的代码保持原样，除非用户明确要求重构
- 每个练习页（`N-M.html`）自包含，样式写在内联 `<style>` 块中
- `index.html` 使用 `lang="zh-CN"`；练习页使用 `lang="en"`，编辑已有页面时保持其 lang 不变
- `css.css` 是独立的样式表练习，不与任何 HTML 文件链接
- 含中文的文件名在 `index.html` 链接中必须使用 URL 编码路径（如 `5-1%E5%B1%82%E5%8F%A0%E4%B8%8E%E7%BB%A7%E6%89%BF.html`），编辑链接时保留该编码

## 5. 新增练习页流程

1. 文件命名为 `N-M.html`（N 为章节号，M 为序号，如 `14-1.html`）
2. 页面自包含：内联 `<style>` 块，所有类名/ID/JS 变量带 `zjq_` 前缀
3. 页头包含注释：`<!-- 姓名：张钧乔，建立时间：YYYY-MM-DD HH:mm:ss，使用的大模型：模型名，功能名称：XXX -->`
4. 在 `index.html` 的 `work-list` 网格中添加对应卡片，链接指向新页面（中文文件名需 URL 编码）

## 6. 完成前检查

- [ ] 新写代码的类名/ID/JS 变量均以 `zjq_` 开头
- [ ] 新建/编辑的 HTML 页面包含姓名、建立时间、使用的大模型、功能名称页头注释
- [ ] 提示词已按格式追加到 `zhang_prompt.md`
- [ ] 新增练习页已在 `index.html` 添加对应卡片
- [ ] `index.html` 中所有链接都能解析到实际文件（注意 URL 编码是否匹配）
