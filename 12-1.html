CSS LENGTH UNITS

CSS 长度单位

从绝对单位到相对单位，从视口单位到容器查询单位——理解 CSS 中各种长度单位的用途与差异。

绝对单位

固定物理尺寸，不随环境变化

px — 像素

150px × 50px

最常用单位。1px 等于设备的一个物理像素（在高 DPI 屏幕上可能对应多个物理像素）。

150px × 50px

pt — 点

100pt

印刷单位，1pt = 1/72 英寸。常用于打印样式表。

100pt

pc — 派卡

10pc

印刷单位，1pc = 12pt = 1/6 英寸。

10pc

cm — 厘米

5cm

物理厘米，1cm = 37.8px。适合打印布局。

5cm

mm — 毫米

50mm

物理毫米，1mm = 3.78px。

50mm

in — 英寸

2in

物理英寸，1in = 96px = 2.54cm。

2in

相对单位

相对于父元素或根元素计算

em — 相对父元素

10em (父元素 14px)

相对于父元素的 font-size。此处父元素为 14px，所以 10em = 140px。

10em = 140px

rem — 相对根元素

10rem

相对于根元素（html）的 font-size。默认 1rem = 16px，不受嵌套影响。

10rem = 160px

em 嵌套特性

父 20px → 子 5em

em 在嵌套时会累积：父元素 20px，子元素 5em = 100px。

5em = 100px

视口单位

相对于浏览器视口大小

vw — 视口宽度

20vw

1vw = 视口宽度的 1%。随窗口宽度变化。

20vw

vh — 视口高度

15vh

1vh = 视口高度的 1%。随窗口高度变化。

15vh

vmin — 视口较小边

15vmin

取 vw 和 vh 中较小值的 1%。

15vmin

vmax — 视口较大边

10vmax

取 vw 和 vh 中较大值的 1%。

10vmax

其他单位

特殊场景使用

% — 百分比

50%

相对于父元素的对应属性值。

50%

ch — 字符宽度

20ch

相对于当前字体中 "0" 字符的宽度。

20ch

ex — 字符高度

10ex

相对于当前字体中 "x" 字符的高度。

10ex
