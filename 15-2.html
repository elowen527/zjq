程序的两种基本结构

顺序、分支、循环是程序的三大流程结构。本页演示 JavaScript 的条件结构（if / else if / else、switch、三元运算符）与循环结构（for、while、do-while、for-of、for-in），全部示例可以点击运行。

一、条件结构：让程序学会选择

条件结构根据判断结果执行不同分支 —— if 适合区间判断，switch 适合离散匹配，三元运算符适合二选一赋值。

if / else if / else —— 成绩评价器

输入 0–100 的分数，程序从上到下依次判断，命中第一个满足的分支后不再往下走。

  • score >= 90优秀
  • score >= 80良好
  • score >= 70中等
  • score >= 60及格
  • 其他情况不及格
输入分数后点击「评价」，看程序命中哪个分支。

switch —— 按星期安排课程

switch 把一个值与各个 case 逐一比对，命中后执行到 break 为止。

点击星期按钮，查看 switch 匹配结果。

二、循环结构：让程序重复劳动

循环由初始化、条件和步进三要素构成。点击每张卡片的「运行」按钮查看逐轮执行过程。

三、组合实战：循环 + 条件

真实程序里两者总是搭配使用：循环负责重复，条件负责筛选。

break 与 continue —— 控制循环的走向

从 1 数到 10：遇到 3 的倍数跳过（continue），数到 8 直接停止（break）。
