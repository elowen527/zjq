异步包饺子

用 Promise 与 async/await 编排一场包饺子流水线：先买原料、再取原料（串行，前一步完成才能开始下一步）；原料到手后和面与和馅同时进行（并行，Promise.all 汇合）；两者都完成后包饺子、最后吃饺子。每一步的耗时用 setTimeout 模拟。

流程演示

点击「开始包饺子」运行整条流水线，总耗时约 21 秒；卡片会随流程实时变为「进行中 / 已完成」。

预计总耗时：21 秒（串行 8s + 并行取最长 5s + 串行 8s）

日志会按时间顺序显示在这里。

核心代码

await 让串行步骤依次执行；Promise.all 把并行的两个 Promise 打包，全部完成才放行。

// 封装 setTimeout 为 Promise：ms 毫秒后自动 resolve
function wait(ms) {
  return new Promise(resolve => setTimeout(resolve, ms));
}

async function makeDumplings() {
  await step('buy', 6000);          // 1. 买原料（6s，串行）
  await step('take', 2000);         // 2. 取原料（2s，串行）
  await Promise.all([              // 3. 和面、和馅（并行）
    step('dough', 4000),
    step('filling', 5000)
  ]);                              // 两个都完成才继续
  await step('wrap', 5000);         // 4. 包饺子（5s）
  await step('eat', 3000);          // 5. 吃饺子（3s）
}
